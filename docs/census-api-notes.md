# Census international trade API — notes

Probed 2026-11-09 against `https://api.census.gov/data/timeseries/intltrade/{imports|exports}/hs`.

## Access

- A key is required. Keyless requests get `302 → /data/missing_key.html`; an
  unknown or not-yet-activated key gets `302 → /data/invalid_key.html`. The key
  goes in the `key=` query parameter (headers are ignored). The pipeline reads it
  from `CENSUS_API_KEY`.

## Variables (confirmed)

| | Imports (for consumption) | Exports |
|---|---|---|
| Country code / name | `CTY_CODE`, `CTY_NAME` | `CTY_CODE`, `CTY_NAME` |
| Commodity / description | `I_COMMODITY`, `I_COMMODITY_SDESC` | `E_COMMODITY`, `E_COMMODITY_SDESC` |
| Quantity / unit | `CON_QY1_MO`, `UNIT_QY1` | `QTY_1_MO`, `UNIT_QY1` |
| Value (USD) | `CON_VAL_MO` | `ALL_VAL_MO` |
| Calculated duty (USD) | `CAL_DUT_MO` | — |

Filters: `COMM_LVL=HS10`, `I_COMMODITY=7606*` (wildcard on the heading),
`time=from+2024-01+to+2024-12` (a range) or `time=2024-01`. The response is a
JSON array of arrays; the first row is the header and also lists the predicate
columns (`time`, `COMM_LVL`, and the commodity column a second time), so columns
are looked up by name, first occurrence.

## History and publication

- Monthly HS10 data is served back to at least 2013-01, so the pipeline starts at
  the planned 2015-01.
- Latest published month at probe time: **2026-09**.
- An unpublished month (or a range wholly after the latest month) answers
  **HTTP 204 with an empty body**. A range that runs past the latest month simply
  returns the months that exist.

## Performance

A heading wildcard over all countries for one month takes ~20–30 s; over a whole
calendar year it takes about the same (~20 s, ~0.5 MB). One request per month per
heading per direction (≈1,400 requests) would take hours, so the pipeline fetches
**one calendar year per request** (≈120 requests) and splits rows by `time`.
A single request once hung for over two minutes; requests have a timeout and
are retried.

## Aggregate country rows

Alongside countries the API returns totals and groupings, which must be dropped:

- `-` TOTAL FOR ALL COUNTRIES
- `0003` European Union, `0014` Pacific Rim, `0017` CAFTA-DR, `0020` USMCA,
  `0021` Twenty Latin American Republics, `0022` OECD, `0023` NATO, `0024` LAFTA,
  `0025` Euro Area, `0026` APEC, `0027` ASEAN
- `1XXX` North America … `7XXX` Africa (continents)

Rule: a row is a country only when `CTY_CODE` matches `^[1-9][0-9]{3}$`.

## Units

Every 10-digit code under the five headings reports quantity in `KG`, in both
directions, for 2015-01 to 2026-09.

## Plate versus sheet (spec open item 1)

Under 7606 the rectangular non-clad codes, and all non-rectangular codes, carry
a 6.3 mm break, so plate (> 6.3 mm) can be isolated:

- **Plate** (> 6.3 mm): 7606113030, 7606123015, 7606123025, 7606123030,
  7606123035, 7606913030, 7606913055, 7606913060, 7606916020, 7606916040,
  7606916055, 7606923025, 7606923030, 7606923060, 7606926020, 7606926040,
  7606926055, and the export-only 7606910010, 7606910050, 7606920010, 7606920050.
- **Sheet** (≤ 6.3 mm): everything else under 7606, including can body/lid
  stock (7606123045/55).
- **Exception:** the two rectangular *clad* codes, 7606116000 and 7606126000,
  have no thickness break (“clad, over 0.2 mm”). They are counted as sheet,
  because clad product is overwhelmingly thin aerospace sheet. They were 4.1% of
  7606 import tonnes in 2024, so plate is slightly undercounted, never
  contaminated.

## Country reference

`pipeline/country-reference.json` joins the Census Schedule C country list
(https://www.census.gov/foreign-trade/schedules/c/country.txt, code → name and
ISO code) with representative coordinates from the `world-countries` package
(v5.1.0, `latlng`). Kosovo (4803), Gaza Strip (5082), and West Bank (5083) have
no match there and were placed by hand. A Census code missing from the file
fails validation.
